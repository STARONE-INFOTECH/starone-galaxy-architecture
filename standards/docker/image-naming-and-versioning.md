# Image Naming and Versioning

## Naming Convention

starone/<service-name>:<version>

Examples:

starone/api-gateway:1.0.0
starone/eureka-registry:1.0.0
starone/customer-service:1.0.0

## Versioning

Semantic Versioning shall be used.

MAJOR.MINOR.PATCH

Examples:

1.0.0
1.1.0
1.1.1

The `latest` tag shall not be used for production deployments.
